# Benchmarking report snapshot

This folder contains one curated, reproducible snapshot from the current temporal evaluation protocol. It is committed so GitHub readers can inspect the visuals without first running the pipeline.

- [CPU benchmark report](cpu/report.md)
- [GPU benchmark report](gpu/report.md)

New runtime reports are written to `outputs/reports/` and intentionally excluded from version control. This prevents each local experiment from inflating the repository.
